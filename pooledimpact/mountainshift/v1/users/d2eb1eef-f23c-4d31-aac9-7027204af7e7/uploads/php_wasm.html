ManifoldAI integration: PHP WASM is the server-side kernel of Mountain Shift OS running browser-local. Laravel Eloquent ORM manages ManifoldAI nodes/edges. PHP validates geometric constraints before any token is emitted. The Pinch fires in PHP before reaching the LLM layer.
Architecture
How it works: PHP runs via WebAssembly using the php.js WASM build. The entire PHP runtime is compiled to WASM and executed in your browser sandbox. No server. No network call. No data leaves your machine.

Mountain Shift OS role: PHP WASM is the application kernel — Laravel 12 routes, Eloquent ORM, Livewire reactive bindings all run here. ManifoldAI nodes are PHP Eloquent models. Graph traversal is PHP code. The Pinch (UndefinedStateError) is a PHP exception caught before the LLM sees the output.
