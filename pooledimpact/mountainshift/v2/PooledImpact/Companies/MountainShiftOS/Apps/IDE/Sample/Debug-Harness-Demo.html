Debug Harness — State / AST / Native-Hook

Three debugging surfaces, each covered by primitives already in the stack (BaseClassX $debug, DomainNode-style AST, targeted native hooks) — no external debugger dependency. Use the job table below like a real shell: ps / fg <id> / bg <id> / kill <id>.

Job 1 — State-Layer Debugging (BaseClassX native)

A live BaseClassX instance. Every property write is traced automatically by the Proxy set trap. $break registers a conditional breakpoint — the condition must be a function called as bp.condition(this), not a string expression. Calling $pause() runs _checkBreakpoints() and flips isPaused. $trace/$dump read state without any external tooling.
