Inverse Design

Set property ranges, not candidate molecules. Every filter below is a real, already-derived quantity from this project's own modules (see MolecularReport.js) run once over the fixed molecule library -- nothing here is generated or screened, it's the existing library filtered by combinable range constraints. A molecule for which a property is not applicable (no conjugated pi-system for a pi-electron property, for example) is excluded from that filter rather than silently scored zero.

Advanced: generate, don't hard-code

The filters above only ever check membership in the same fixed ten molecules. This generates real candidates instead -- deterministically (a bounded, exhaustive enumeration, never a trained model or a statistical search) -- and evaluates every one through the exact same MolecularReport.js pipeline, checked against whichever filters above are enabled. Generation and evaluation aren't instant the way filtering ten cached rows is, so this runs on demand rather than live: set the mode and bounds, then hit Go.
