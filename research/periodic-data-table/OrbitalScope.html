Orbital Scope

Four live point clouds, one per orbital block, each shaped by rejection-sampling the real spherical-harmonic magnitude for its type instead of a fixed density cutoff — the difference between an actual dumbbell and a sphere with a thin gap in it.

Drag a scope to orbit it · scroll to zoom · Set Element accepts any symbol and swaps its shape list to match that element's real block.

How the cloud is built — each point is accepted with probability proportional to its orbital's real angular density, normalized against that function's true analytic maximum (accept < density / max), not a pass/fail threshold. Shell radius comes from each element's own Slater radius (FVT's Zeff-derived screening estimate), so heavier, tighter atoms render a visibly smaller cloud than light ones — try typing Fr into a scope next to Fe and compare.
