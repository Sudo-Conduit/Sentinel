Molecule Viewer

Every structure here is built the same way: a molecule's graph — from the reference set below, or typed in as SMILES — run through MolecularStructure.js for real per-atom hybridization/lone-pair/formal-charge derivation, then MolecularGeometry.js for idealized VSEPR 3D coordinates — textbook electron-domain geometry, not a measured crystal or NMR structure.

Drag to orbit · Cmd+drag to pan · scroll to zoom.

Geometry source is always labeled in the panel to the right — idealized (VSEPR) means every atom's own bond angles are mechanically exact for its steric number (109.47° tetrahedral, 120° trigonal planar, 180° linear…), derived the same "textbook, not guessed" way as everything else in this project. Ring-closure bonds (pink) are the one honest exception: a simple spanning-tree placement can't solve true ring/macrocycle closure, so that bond's real resulting length is reported and flagged rather than silently assumed correct — true ring 3D embedding needs real conformer generation, which is out of scope for this module. Real imported coordinates (PDB/MOL/XYZ) are a deliberately separate, not-yet-built path so the two are never confused for each other.
